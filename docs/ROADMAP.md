# Roadmap

The literal sequence I follow every time I start a new build from this template.

1. Define intent + constraints — fill out `SYSTEM_CHARTER.md` before opening the editor.
2. Sketch the system in words — one sentence for signal, parameter, behavior, readability test.
3. Build the smallest working version — canvas boots, loop runs, one input is captured.
4. Iterate through visible tests — change one variable at a time, check it against the readability test.
5. Polish only after meaning is legible — styling, easing, and extra behavior come last.
6. Deploy and log — push, confirm the live link works, note the change in `process/changelog.md`.
