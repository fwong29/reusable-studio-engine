every number costs as many taps as its value
how it works
The number key builds a value by tapping — a 7 costs seven taps, everywhere. Type an expression in x to graph it. Turn on d/dx to see the derivative, or ∫ to shade an area — click a bound box, then multi-tap the number. Keyboard: space = tap, x, ( ), r = root, = / Enter, Backspace, Esc.
