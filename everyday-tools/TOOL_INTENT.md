# Tool Intent Statement

**Working title:** Weight

## 1. Core Function
A working calculator with one number key. Entering a number takes that many taps — 7 is seven taps, 1 is one tap. Operators, "=", "C", and "⌫" register on the first press.

## 2. Human Context
Normal keypads make every digit cost the same single tap, so a quantity can grow without ever being felt growing. This gives the number back its own weight on the way in.

## 3. Intended User
Someone doing ordinary arithmetic — a tab, a quantity, a count — who'd rather feel a big number arrive than have it appear for free.

## 4. Behavioral Thesis
Friction sized to the number, not to the person or their history — fixed from first use, the same for everyone, forever.

## 5. Dignity Clause
Records nothing. Doesn't know or comment on what the number means. No streak, no score, no comparison.

## 6. Refusal Clause
Won't track, log, or sync. Won't gamify or shame. Won't get harder or easier with use — the rule never changes. Won't name the behavior being counted: naming it would require the tool to know what you're counting, and refusing to know is the dignity position.

## 7. Atmospheric Tone
Physical and unhurried, like an old adding machine. Warm, quiet, matter-of-fact about its own friction.
